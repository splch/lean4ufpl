# UFPL - Unified Formal Philosophy Language (Lean 4)

A minimal, typed, multi-modal higher-order logic for philosophy, with Kripke/relational semantics.

## Build & run

```bash
lake build
lake exe ufpl
```

## Structure

* `UFPL/Core`: types, syntax, semantics
* `UFPL/Examples`: small models (Necessity of Identity; Trolley case)
